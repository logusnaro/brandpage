# logUs Studio — Brand Page

Brand hub for **logUs Studio** (로그어스스튜디오).

**Domain:** [logusstudio.com](https://logusstudio.com)  
**Stack:** Next.js · Tailwind · Sanity (`/admin`) · Vercel

## Quick start

```bash
npm install
npm run dev
```

- Site: http://localhost:3000  
- Admin: http://localhost:3000/admin  

Until Sanity has content, the page uses seed fallback from `docs/PLANNING.md` (`[:]bebe` Coming soon + Threads).

### Seed CMS (optional)

1. Create an Editor token in [Sanity Manage](https://www.sanity.io/manage)
2. Put it in `.env.local` as `SANITY_API_WRITE_TOKEN`
3. Run:

```bash
npm run seed
```
