# logUs Studio — Brand assets

Generated for local brand-page development. Flat, minimal, B&W (`#111111` on white / white on black). Typography intent: **Inter SemiBold**, tight tracking.

| File | Use |
|------|-----|
| `logo-text-horizontal.png` | Wordmark: logUs Studio |
| `logo-text-horizontal-inverse.png` | Wordmark on black |
| `logo-symbol.png` | Symbol alone: `[:]` (favicon / app icon base) |
| `logo-symbol-inverse.png` | Symbol on black |
| `logo-lockup-horizontal.png` | `[:]` + logUs Studio (header) |
| `logo-lockup-vertical.png` | Stacked: `[:]` over logUs Studio |

## Rules

- No gradient, shadow, or 3D
- Primary color `#111111`
- Site `:` blink matches logo black
- Prefer **SVG/webfont Inter** in production code; these PNGs are reference + OG/favicon sources
