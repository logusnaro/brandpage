# logUs 브랜드 운영시스템

## 목적

홈페이지 콘텐츠, 서비스 릴리스, 약관·정책, 서비스별 logU 캐릭터를 한 곳에서 관리한다. 공개 페이지에는 공개로 지정된 최신 콘텐츠만 노출하고, 비공개 파일은 운영자 또는 발급된 제한 링크를 가진 사람만 접근한다.

## 관리 메뉴

1. 대시보드
   - 홈페이지 게시 상태
   - 서비스별 최신 릴리스
   - 초안·검토 필요 항목
   - 최근 변경 기록
2. 홈페이지
   - Intro 문구와 이미지
   - Product 카드·설명·노출 순서
   - Contact 문구·연락처
   - 한국어/영어 콘텐츠
3. 서비스
   - 서비스명, 설명, 공개 여부, 홈페이지 노출 여부
   - 서비스별 logU 연결
4. 릴리스
   - Android APK, 웹앱 URL, 추후 iOS
   - 버전, 배포일, 변경사항
   - 공개/비공개/제한 공유
   - 서비스별 플랫폼 최신 버전 1개만 공개
5. 약관·정책
   - 이용약관, 개인정보처리방침, 환불정책, 기타
   - 서비스별 문서와 버전·시행일·게시 상태
6. logU 캐릭터
   - 서비스별 캐릭터 이름과 연결
   - 대표 이미지·표정 이미지
   - 성격, 기억의 테마, 색상, 메모
   - draft/active/archived 상태
7. 브랜드 운영
   - 중앙화 폴더 대시보드의 공개용 요약
   - 프로젝트·운영 문서 링크
   - 로컬 `0.logUs` 경로 자체는 서버에 노출하지 않음

## 공개 규칙

- 홈페이지에 게시된 서비스만 공개 다운로드 영역에 표시한다.
- 공개 릴리스는 서비스·플랫폼별 최신 1개만 표시한다.
- 공개 APK/Web URL은 `status=published`, `visibility=public`, `isLatest=true` 조건을 모두 만족해야 한다.
- 이전 릴리스와 비공개 릴리스는 공개 목록에서 제외한다.
- 비공개 파일은 관리자 인증 후에만 관리할 수 있다.
- 제한 공유는 만료시간이 있는 서명 링크로 제공한다. 원본 저장소 URL은 노출하지 않는다.

## 저장소 역할

- Sanity: 문구, 서비스, 릴리스 메타데이터, 약관·정책, logU 캐릭터 정보
- Cloudflare R2: APK 및 대용량 파일 원본
- Vercel: 홈페이지와 어드민 웹 실행
- Google OAuth: 단일 운영자 로그인

## 인증 원칙

운영자 계정은 `logus.naro@gmail.com` 하나로 제한한다. Google OAuth 환경변수와 허용 이메일 검사를 모두 통과하기 전에는 어드민 쓰기 기능을 활성화하지 않는다. 인증 없는 어드민 화면에서 Sanity 토큰이나 R2 키를 브라우저로 전달하지 않는다.

## 중앙화 대시보드 연결

현재 로컬 `logus-brand-structure.html`은 `C:\Users\jkhon\0.logUs`를 직접 읽는 정적 도구다. 그대로 공개 호스팅하지 않고, 추후 서버에서 허용된 요약 데이터만 생성해 어드민의 브랜드 운영 메뉴에 표시한다. 개인 경로, 파일 목록 전체, 내부 문서는 외부에 노출하지 않는다.

## 현재 구현 상태

- Sanity 스키마: `mascot`, `appRelease`, `legalDocument` 추가
- Sanity 메뉴: logU 캐릭터 관리, 앱 릴리스 관리, 약관·정책 관리 추가
- 자체 어드민 `/manage`: 대시보드, 콘텐츠 연결, APK 등록·목록·관리자 다운로드 구현
- Google OAuth: `logus.naro@gmail.com` 단일 계정 제한 구현, OAuth 클라이언트 연결 대기
- R2: 비공개 원본 업로드와 5분 다운로드 URL 구현, 버킷·API 토큰 연결 대기
- 제한 공유: 7일 동안 유효한 서명 링크 발급 구현
- 문의 폼: Sanity 문의함 저장 구현
- Intro 문구: Sanity에서 수정한 문구가 실제 홈페이지에 반영되도록 수정
