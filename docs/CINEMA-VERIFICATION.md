# 영상형 홈페이지 구현·검증 · 2026-10-04

로컬: http://localhost:3001/ · 브랜치: feature/video-homepage.

## 구현

15초 60fps 인트로: 데스크톱 무자막·브랜드 제목 포함·모바일 세로 3종. Canvas의 연속 좌표 카메라, 이징, 전경 안개 패럴랙스, 입자 곡선 이동, 시차를 둔 구름 전환, 시간 샘플링 모션 블러, 마지막 홀드. 웹에서는 HTML 제목을 별도로 순차 표시한다.

신규 홈페이지: 마을 영상 → logU 철학·다양한 삶의 장면 → 제품별 마스코트·DayByBaby 5편 선택 → Contact. 한국어 기본·영어 선택, Pretendard, 반응형 스타일과 모바일 전용 영상, 정지/건너뛰기/재생 제어, reduced-motion 대응.

기존 Sanity 제품/문의/관리자 인증 API 유지. 새 철학·제목·사진 설명 등은 cinema 그룹에서 한국어/영어로 편집 가능. 앱 영상은 기존 ppuri-v2 5편을 유지한다.
