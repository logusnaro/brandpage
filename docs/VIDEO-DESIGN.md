# logUs Studio · A world of little moments

2026-10-04 · 파운더 승인 범위: 영상과 홈페이지 전면 재설계·로컬 적용. 화면 캡처 제외, 영상·코드 검증.

## 디자인 계약

logU는 흘러가는 순간을 담고 간직하는 기억의 조약돌. 다양한 logU가 각자의 앱을 만들며 하나의 logUs 세계를 이룬다. 기능 수나 성과를 자랑하기보다 일상의 순간과 곁을 지키는 존재를 보여준다.

- Ivory `#f3f0e8`: 구름의 마지막 프레임과 사이트 공통 표면.
- Pine `#253b31`: 주 글씨·철학 섹션. Coral `#c77560`: 작은 구두점·선택 상태.
- Pretendard Variable 단일 폰트. 큰 제목은 560–650, 본문은 400. 최소 설명·큰 이미지·일관된 왼쪽 기준선.
- 고정 상단: 브랜드·Studio/Apps/Contact·한영 선택. 모바일은 짧은 내비게이션.
- Full-screen film → 철학 → DayByBaby의 푸리와 선택형 영상 → Contact.
- 다양한 logU는 기존 마을과 생활 장면을 사용. 출시 상태나 다른 앱의 마스코트 이름을 임의로 만들지 않는다.
- 영상은 15초, 60fps. 자동 무음 재생, 건너뛰기/정지/다시보기. 앱 영상은 클릭 후 재생.
- reduced-motion에서는 정적 포스터와 즉시 나타나는 제목. 텍스트는 영상 밖에서 한영 전환.
- 화면 760px 이하에서는 한 열, 제목 줄바꿈, 영상 선택 가로 스크롤, 세로영상은 9:16 유지.
- 관리자 인증·Sanity·문의 API 유지. 홈페이지 편집 가능한 기존 문구와 제품 데이터는 계속 CMS에서 받는다.

## 15초 모션 연출

0–1초: 마을 입구에서 짧은 홀드·미세한 예비 후퇴.
1–5.8초: 길을 따라 천천히 접근, 전경 안개와 기억 입자의 거리별 속도차.
5.8–8.8초: 마을 중심을 맞춘 확대와 전경 구름 전환으로 높은 시점으로 이동, 빠른 구간 시간 샘플링 모션 블러.
8.8–12초: 곡선 상승, 구름의 부위별 시간차, 구름 사이에서 아이보리 표면 등장.
12–15초: 화면이 안정된 채 브랜드 제목 순차 등장·홀드. 웹 표시와 독립 영상용 제목판을 각각 제공.

과도한 지속 흔들림·불필요한 휩 팬·숫자 카운트업은 사용하지 않는다. 모든 효과를 넣는 것보다 동선과 정지 지점을 일관되게 한다.

## 재제작

`node scripts/render-intro.cjs`: 원본 사진 3장을 Canvas로 합성하여 데스크톱 무자막·브랜드 제목 포함·모바일 세로 MP4 생성. 실제 3D 카메라나 생성형 캐릭터 애니메이션이 아닌 이미지 기반 모션그래픽이다. 웹의 브랜드 제목은 HTML/CSS로 별도 표시한다. 앱 영상 5편은 기존 ppuri-v2를 사용한다.
