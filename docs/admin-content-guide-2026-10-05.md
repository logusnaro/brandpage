# 홈페이지 콘텐츠 관리 · 2026-10-05

## 작업 범위

기존 Sanity 관리자와 현재 디자인을 재사용한다. 새로운 DB·권한·업로드 서버는 만들지 않는다. 공개 콘텐츠 편집 필드를 추가하고 실제 화면으로 연결한다. 운영 데이터 게시·이관·배포는 하지 않는다.

## 어디에서 무엇을 바꾸나

관리자 진입: `/manage` → 콘텐츠 카드 → Sanity `/admin`. 기존 Google 계정과 Sanity 프로젝트 권한을 사용한다.

## 현재 네 앱을 처음 등록할 때

먼저 서비스 목록에서 기존 문서를 찾는다. 이미 있으면 **새로 만들지 말고 기존 문서를 수정**한다. 이름 변경과 별개로 내부 slug는 유지한다.

문서가 없다면 새 문서 메뉴의 `DayByBaby/MemoGrip/GoodGo/BookBap 기본 소개로 시작` 템플릿을 사용한다. 기본 제목·설명·분류·플랫폼 계획이 채워지고 **소개 상태는 Draft**다. 템플릿을 여는 것만으로 저장·공개되지 않는다.

서비스 특징 목록을 입력하지 않으면 현재 기본 특징과 삽화를 유지한다. 새 특징을 직접 입력하면 해당 목록으로 교체되므로 원하는 문구와 기능 이미지를 함께 넣는다. 빈 특징/영상 목록 `[]`을 저장하면 해당 영역이 숨겨진다. DayByBaby 영상 미설정 시 기존 영상 5개를 유지하며 다른 앱은 영상 미설정 시 영역을 숨긴다.

서비스 소개를 공개할 때는 소개 상태를 Published로 설정하고 **Sanity의 Publish도 눌러야** 한다. 기존 네 앱은 승인된 기본 소개가 이미 화면에 있으므로 Draft 문서만 만들면 기본 소개가 유지된다. 홈페이지에서 아예 숨기려면 소개 상태를 Unpublished로 설정 후 Publish한다. 스토어 출시 상태는 소개 공개 상태와 별개다.

## 영상과 이미지 교체

- 이미지는 Sanity 이미지 업로드로 교체한다. 이미지 비율·크기·배치는 현재 레이아웃이 정한다. 사진 내 글자는 이미지 자체에 포함되므로 관리자 문구 설정으로 수정되지 않는다.
- 인트로는 `/films/파일.mp4` 또는 외부 HTTPS MP4 주소만 허용한다. 외부 저장소에는 직접 재생 가능한 공개 주소가 필요하다. R2 비공개 APK·공유 링크 체계는 변경하지 않았다.
- PC 영상만 교체하고 모바일을 비워두면 모바일에도 새 PC 영상을 사용한다. PC도 비어 있으면 원래 모바일 영상을 유지한다.
- 기본 영상은 기존 15초 흐름을 유지한다. 새 영상의 브랜드명 등장 시점은 종료 약 3.2초 전 또는 설정한 초이며, 영상 길이에 맞춰 제한된다.
- 서비스 영상은 기존 기능대로 MP4 또는 YouTube 링크와 미리보기 사진을 넣는다. 가로 영상은 본문 플레이어, 세로 영상은 추가 영상 링크다. **세로 영상만 등록하면 현재 본문 영상 영역이 표시되지 않는 기존 제약**이 있으므로 가로 영상도 함께 넣는다. 해당 개선은 별도 작업으로 남겼다.

## 저장과 반영

편집 중에는 초안이고, Publish 후 공개 화면에 반영된다. 홈페이지는 기존 60초 재검증과 Sanity CDN 캐시를 사용하므로 즉시 반영을 보장하지 않는다. 처음 확인할 때 캐시 시간을 기다리고 새로고침한다. 실서비스 게시 전 한국어·영어 문구와 실제 다운로드 주소를 확인한다.

관리자 콘텐츠는 공개 홈페이지용이다. 개인정보·비밀키·내부 파일을 여기에 넣지 않는다. 개인정보 동의 문구 수정은 실제 처리 내용과 일치해야 한다. 법률 문구의 적정성은 이번 코드 작업에서 검토하지 않았다.

## 검증 기록

아래는 구현 완료 후 실행 결과를 기재한다. 실제 계정으로 편집→Publish→공개 반영은 운영 콘텐츠 변경이므로 이번 자리비움 작업에서 실행하지 않는다. 화면 검수·캡처도 이번 요청에서 별도 승인되지 않아 실행하지 않는다.

### 코드리뷰

편집값이 조회 쿼리→설정 병합→홈페이지/목록/상세에 전달되는지 확인했다. 번역된 서비스명을 바꾸면 DayByBaby 이름이 무시되거나 다른 앱 상세 스타일이 바뀌는 연결 문제를 보완했다. 오래된 Intro 4장 입력을 현재 영상형 홈페이지의 게시 필수조건으로 요구하지 않도록 선택형으로 바꿨다. 기존 데이터 삭제나 자동 게시 없음.

React 검토: HTML 문자열 삽입 없음, CMS 문구는 React의 텍스트 처리, 폼 필드명·필수 입력·동의·전송 동작 보존. 신규 클라이언트 요청·의존성·인증 변경 없음. 이미지는 기존 Sanity CDN 제한을 사용. 인트로 주소는 HTTPS MP4 또는 안전한 로컬 MP4로 제한하고 상대 프로토콜·상위 경로·계정 포함 URL·잘못된 스킴은 기본 영상으로 대체한다.

검토 중 발견한 **기존** 세로 영상 단독 등록 제약은 위 사용법에 기록했으며 이번 작업에서 디자인을 바꾸지 않았다. 실제 Sanity 계정에서 이미지 업로드·문구 저장·Publish·캐시 후 반영, 실제 모바일 및 관리자 실화면은 미검증이다. 이 항목들을 확인하기 전 병합 판정은 조건부이며 자동 병합·배포하지 않는다.
