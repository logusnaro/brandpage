# MemoGrip · GOODgo · BookBap 영상

요청: DayByBaby와 같은 구성의 앱 소개/가이드 영상을 제공 음악으로 제작. `02_shared/design/MOTION-GRAPHICS-GUIDE.md` 적용.

## 결과 구성

앱마다 가로 소개 20초, 가로 가이드 35초, 가로 소개+가이드 90초, 세로 소개 20초, 세로 가이드 35초. 총 15개.

- MP4 / H.264 / 1080p / 24fps / AAC stereo 48kHz. 음성 나레이션 없음.
- `public/films/apps-2026-10-06/index.html`: 전체 감상·MP4 다운로드·SRT 자막.
- `public/films/apps-2026-10-06/manifest.json`: 완성 파일별 실제 제작 정보.
- 기존 DayByBaby 영상 및 음악 원본은 수정하지 않음.
- 앱 상세페이지 기본 영상으로 연결. 어드민의 영상 목록을 설정하면 설정값 우선, 빈 배열로 저장하면 기본 영상도 숨김.
- 새 소개/가이드의 문구는 한국어. 사이트의 한국어/영어 영상 선택 UI는 유지. 영어판 영상 자체는 이번 요청 범위가 아님.

## 앱별 차별점과 음악

| 앱 | 소개 핵심 | 음악 |
| --- | --- | --- |
| MemoGrip | 자유롭게 한 줄 기록 → 실제 규칙 기반 일정 분류 → 아이디어·노트·기록 | Toys Are Us — Blue Deer Studio |
| GOODgo | 도착 기준 역산 → 준비/출발 시각 → 체크리스트·반복 폴더 | Robot Boogie — Quincas Moreira |
| BookBap | 나만의 책장 → 문장과 생각의 Assets → 독서 흐름 기록 | Paseo Nocturno — Luna Cantina |

제공 음원의 공개 배포 이용 조건은 확인하지 않았으므로 공개 게시 전 확인 필요. 원본 MP3는 웹에 복사하지 않았으며 영상에만 합성.

## 모션 가이드 적용

- 이징: cubic smoothstep, 등장 0.85초, 전환 0.85초.
- 오버랩·스태거: 이미지와 설명을 0.08/0.13초 지연해 순차 등장.
- 매치컷: 가이드의 기기 위치와 크기를 동일하게 고정.
- 마스크 리빌: 둥근 이미지·기기 클립 영역과 부드러운 등장.
- 홀드: 소개 한 장면 5초, 짧은 가이드 7초, 긴 영상 10초.
- 푸시 인: 일러스트에만 한 장면 최대 1.2%의 매우 느린 확대.
- 키네틱 타이포: 12px 이내의 짧고 감속되는 등장. 지속 흔들림/바운스 없음.
- 시작/끝: 페이드 인 및 음악 페이드 아웃. 자동 반복 영상 아님.
- 21개 효과를 억지로 전부 넣지 않음. Hyperframes/After Effects를 사용했다고 주장하지 않음. 실제 방식은 결정적 Canvas 타임라인 + Playwright + FFmpeg.

## 화면 근거와 안전

원본 앱 폴더를 별도 작업 폴더에 복사하고, 실제 UI에 로컬 예시 데이터만 사용.

- MemoGrip: 원본 App/store UI, 원본 `ruleClassify` 사용. 저장/분류는 메모리 어댑터에서 실제 수행. 라이브 AI 실행 장면을 꾸미지 않음.
- GOODgo: `readygo/design-preview/index.html`의 오프라인 프리뷰. 지도/날씨 등 실시간 서버 기능 실행을 증명하는 영상이 아님.
- BookBap: 원본 App UI와 로컬 기본 예시 데이터. 실제 계정 인증·클라우드 쓰기 없음.
- 모든 촬영 컨텍스트는 localhost 외 네트워크 요청 차단. 운영 데이터 변경 없음.
- 미완성 기능(브라우저 닫힌 상태의 알림 보장, 무제한 AI, 사진 클라우드 백업 등)은 소개하지 않음.
- 녹화 화면에는 ‘앱 개발 화면 · 예시 데이터’ 표시.
