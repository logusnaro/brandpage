## 게시 전 보안 패치

`npm audit --omit=dev --audit-level=high`에서 기존 Next 16.3.4 critical 경고가 발견되어 게시를 잠시 보류하고 Next / eslint-config-next를 **16.3.6**으로 고정했다. React/Sanity 버전·서비스 코드·UI는 변경하지 않았고, 강제 audit fix는 사용하지 않았다. npm 설치는 5개 패키지만 변경.

공식 [GHSA-vcvr-r3jv-pc5j](https://github.com/advisories/GHSA-vcvr-r3jv-pc5j), [v16.3.6 보안 릴리스](https://github.com/vercel/next.js/releases/tag/v16.3.6)를 2026-10-06 확인. 영향 조건은 Node ImageResponse의 공격자 제어 SVG이며, 현재 OG는 고정 div/span과 관리자 CMS 텍스트만 사용하므로 그 조건의 노출 증거는 없었다. 그래도 수정 버전으로 패치하고 재빌드·회귀 검사.

나머지 high 경고는 Sanity CLI/codegen/workbench의 ZIP·glob·YAML·module-federation 하위 의존성이다. `.next/server/**/*.nft.json`을 실제 읽어 `adm-zip`, `brace-expansion`, `braces`, `js-yaml`, `@module-federation` 모두 배포 서버 추적 파일 0개 확인. 서버 코드가 ZIP 해제나 사용자 glob/YAML 파싱을 제공하지 않는다. 따라서 웹 런타임 차단 finding으로 판정하지 않고 CLI 후속 관리 경고로 남김. DOMPurify 등 lower-severity 경고도 전체 소멸했다고 보고하지 않음. 상태 PASS WITH WARNINGS(해당 미디어 게시 범위).
